## 2. 今晚重点：时频建模（建议先学这块）

目标：能用自己的话讲「波形怎么变成频谱、Mel 是什么、相位是什么」。下面按顺序看，每条能讲 30 秒再打勾。

### 2.1 波形（时域）

- [ ] 声音在计算机里是 **一维序列** \(x[n]\)，每个点是振幅。
- [ ] **采样率 \(f_s\)**：每秒多少个点。电话/很多语音模型 16 kHz；你项目里常见 22.05 kHz 或 48 kHz。
- [ ] **奈奎斯特：** 能表示的最高频率大约是 \(f_s/2\)。16 kHz 采样，最高约 8 kHz。
- [ ] 语音：浊音有基频 F0（音高）和共振峰；清音/辅音能量更散、更靠高频。所以乱滤高频会「口齿不清」。

### 2.2 为什么要时频

- [ ] 纯时域：看波形，噪声和语音叠在一起，难分开。
- [ ] 纯 FFT 整段：只有一张总频谱，**没有时间变化**（谁先说话、噪声何时出现都不知道）。
- [ ] **时频：** 把信号切成短帧，每帧做频谱 → 横轴时间、纵轴频率，这就是语谱图。增强、识别、很多生成模型都在这张图上干活。

### 2.3 STFT（短时傅里叶变换）——今晚核心

一帧的做法：取出一段波形 → 乘窗 → FFT → 得到这一帧各个频率的复数。

要记住的三个参数：

| 参数 | 含义 | 变大了会怎样 |
| --- | --- | --- |
| 窗长 / `n_fft` / `win_length` | 一帧覆盖多长时间 | 频率更细，时间更糊，延迟更大 |
| 帧移 / `hop_length` | 下一帧跳多远 |  hop 大：帧少、算得快、时间更稀、延迟相关 |
| 窗函数（常用 Hann） | 避免截断造成频谱泄漏 | 一般别用矩形窗 |

- [ ] 常见数量级：16 kHz 时，窗长 20–32 ms（约 320–512 点），hop 10 ms（约 160 点），重叠 50% 很常见。
- [ ] **OLA（重叠相加）：** 还原波形时把各帧加回去，重叠是为了接得平滑。
- [ ] **ISTFT：** 频谱变回波形。训练里若损失在频谱上，有时还要 ISTFT 再听。

**口答：** 窗长换频率分辨率，帧移换时间分辨率；实时系统 hop 不能太大也不能为了细频率把窗拉得很长，否则延迟高。

### 2.4 幅度、相位、能量、dB

FFT 每个频率点是 **复数** \(a+bi\)：

- [ ] **幅度** \(|X|=\sqrt{a^2+b^2}\)：这一频率有多「响」，听感主要看它。
- [ ] **相位** \(\angle X\)：正弦从哪一时刻开始。单独看相位图很难懂，但还原波形必须要相位（或用别的办法估）。
- [ ] **功率/能量：** 幅度的平方。
- [ ] **dB：** \(20\log_{10}|X|\)（幅度）或 \(10\log_{10}\)（功率），把很大的动态范围压到好画、好算的尺度。
- [ ] **对数幅度 / log-mel：** 生成模型常用，更接近人耳对响度的感觉。

很多降噪会：估一个更好的幅度，相位先继续用带噪的（省事、能实时）。质量要求高再估复谱或直接时域。你能说到这一层就够，不必说自己做过。

### 2.5 Mel 频谱（你项目里用过，要能解释）

- [ ] 人耳对低频更敏感：同样是 100 Hz 的差别，在低音区比高音区更容易分辨。
- [ ] **Mel 刻度：** 把 Hz 非线性地弯一下，低频分得细、高频分得粗。
- [ ] **Mel 滤波器组：** 在 STFT 幅度上乘一组三角滤波，得到 Mel 频带能量，再常取 log → **log-mel**。
- [ ] 维数通常 64/80/128，远小于 FFT 点数（如 513），所以省计算、适合当神经网络输入。
- [ ] **局限：** Mel 已经丢掉一部分频率细节和相位；**语音增强要精细恢复谐波和辅音时，常用线性频谱或波形，不一定 Mel。** 生成/TTS 更爱 Mel。

被问「你用的 Mel 和降噪频谱一样吗」：

> 我训练生成模型时主要用 Mel 或模型自己的时频特征。增强文献里也常用线性 STFT 或波形。Mel 是感知压缩后的，细节更少。具体用哪种我还在学。

### 2.6 滤波器（JD 要求，用直觉即可）

- [ ] **低通：** 放低频、挡高频。去高频嘶声，但可能伤齿音（s、sh）。
- [ ] **高通：** 去低频隆隆声、风噪的一部分，可能伤男声胸腔感。
- [ ] **带通：** 只留中间一段（比如电话频带）。
- [ ] **陷波：** 去掉某一个嗡嗡频点（电流声 50 Hz 等）。
- [ ] FIR / IIR：FIR 更稳、可做成线性相位；IIR 更省，但要小心不稳定。面试能说「滤波就是在频率上加权」即可。

你项目里「滤波当攻击」：可以理解为频谱被改过，模型还能不能工作；不要说成自己设计过滤波器。

### 2.7 时频图上，模型在干什么（建立直觉，不对应你做过 NS）

- [ ] 语谱图可以当成「时间 × 频率」的二维图，CNN/U-Net 会在这上面滑。
- [ ] 语音谐波在语谱图上是横着随时间走的一条条纹；噪声常常更散。
- [ ] 增强的一种常见想法：学一个 **mask（0~1 的权重）** 乘在带噪频谱上，把噪声格子压小、语音格子留下。这是在读论文，不是我的项目经验。

### 2.8 今晚时频自测（闭卷）

1. 采样率 16 kHz，理论上最高频率大约多少？
2. 为什么整段 FFT 不够，要用 STFT？
3. 窗长变长，频率和时间分辨率谁更好、谁更差？
4. 幅度和相位哪个更影响「响不响」，还原波形能不能不要相位？
5. Mel 相对线性频谱，低频和高频谁分得更细？增强为什么不一定用 Mel？
6. hop 变大，计算量和时间轴密度怎么变？
7. 低通滤波可能伤语音的哪类音？
8. dB 是在做什么？

答案要点：1）8 kHz；2）要时间变化；3）频率更好、时间更差；4）响度看幅度，还原一般要相位或替代估计；5）低频更细，增强常要更细的线性谱/波形；6）算得少、时间更稀；7）高频辅音/齿音；8）把幅度压到对数尺度。

## 3. 语音增强：只记任务，不装会模型

- [ ] 输入带噪 \(y\)，输出干净语音估计 \(\hat{s}\)；最常见 \(y=s+n\)。
- [ ] 和 TTS（无中生有说话）、分离（两人叠在一起）不同。
- [ ] 通话往往要 **因果**（不能看未来很多帧）、看延迟和 RTF。
- [ ] 评测名字：SI-SDR、PESQ、STOI；你用过 PESQ/SNR/MOS，可以说「PESQ 我在生成音频里用过，STOI/SI-SDR 是增强里更常见的可懂度和失真指标，我还在补」。
