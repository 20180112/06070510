## 1. 今晚必过（模型向，优先按这个顺序）

### 1.1 任务定义（先能开口）

- [ ] 观测：带噪语音 \(y = s + n\)（加性噪声是最常见假设；也有混响 \(y = s * h + n\)）
- [ ] 目标：从 \(y\) 估计干净语音 \(\hat{s}\)
- [ ] 和「语音分离」「回声消除 AEC」「去混响」的差别（NS 主打噪声；AEC 是参考回路；去混响是冲激响应）
- [ ] 离线 vs **流式/因果**：端侧通话通常要因果、低延迟，不能看未来很多帧
- [ ] 实时指标：延迟（算法延迟 + 帧移）、RTF（处理时长 / 音频时长，要 < 1）

### 1.2 时频：STFT（DSP + 模型共用）

- [ ] FFT / STFT：窗长、帧移、窗函数（Hann）；重叠相加 OLA
- [ ] 幅度谱、相位谱；人耳对幅度更敏感，相位难估但仍影响听感
- [ ] 为什么很多 NS 只估幅度再叠带噪相位（简单、快；高质量会走复谱/时域）
- [ ] Mel 和线性 STFT 的差别：Mel 偏感知、压缩高频；NS 常用线性频谱或复谱，不一定 Mel
- [ ] 滤波器直觉：低通去高频噪声会伤齿音；带通、陷波各干什么

**口答模板：** 窗长决定频率分辨率，帧移决定时间分辨率和延迟；端侧会把窗长/lookahead 压得很短。

### 1.3 传统方法（各会 30 秒）

- [ ] 谱减法：估噪声谱，幅度里减；易有音乐噪声
- [ ] Wiener：按信噪比做增益 \(G = \xi / (1+\xi)\)
- [ ] 噪声估计要 VAD / 最小值跟踪；非平稳噪声会挂

用来衬托深度学习：传统依赖平稳噪声假设，AI NS 更能打非平稳（键盘、babble、风噪）。

### 1.4 深度学习 NS 结构（偏模型，今晚核心）

不必会实现，要能说出「输入–结构–输出–是否因果」。

| 名字 | 记住什么 |
| --- | --- |
| CRN | 卷积编解码 + 中间 LSTM，频谱 mask |
| DCCRN | 复值卷积，直接处理复谱，DNS Challenge 常用基线 |
| NSNet | 微软 DNS 基线，轻量、偏工程对比 |
| RNNoise | GRU + 传统特征，非常适合端侧叙事 |
| Conv-TasNet | 时域 encoder-masker-decoder，分离/增强都常见 |
| FullSubNet / FRCRN | 全频带 + 子带，偏质量 |
| 扩散 SE | 质量高、偏重，**端侧一般不用**；你有扩散经验，对比着说即可 |

- [ ] **Mask 范式：** 网络出 \(M\)，\(\hat{S} = M \odot Y\)（IRM / CRM 复数 mask）
- [ ] **映射范式：** 直接回归干净频谱或波形
- [ ] 时域 vs 频域：时域省相位问题、算力可能更大；频域和 DSP 结合紧、好做流式
- [ ] 端侧更可能是：小 CRN / DCCRN / RNNoise 类，而不是 AudioLDM、大扩散

**被问「你会哪个」：** 诚实说课程/论文读过 DCCRN、CRN、mask 范式；自己实验主线是生成音频和鲁棒性，增强网络可以很快上手。

### 1.5 损失与指标（你简历最能打的一块）

- [ ] 时域：SNR、SI-SDR（去缩放，更看波形匹配）
- [ ] 感知：PESQ、STOI（可懂度）
- [ ] 无参考：DNSMOS（DNS Challenge 常用）
- [ ] 你做过的：PESQ、SNR、FAD、CLAP、MOS —— 增强岗更认 PESQ/STOI/SI-SDR/DNSMOS；FAD/CLAP 是生成质量，别混用
- [ ] 过拟合噪声种类：在一种噪声上 PESQ 高，换场景会崩 → 要多样噪声 + 真实录音

**口答：** 我会同时看失真（SI-SDR）和听感（PESQ/MOS）；端侧还要看 RTF 和量化后掉点。

### 1.6 数据（能报出名字）

- [ ] DNS Challenge（合成 + 真实，工业界常用）
- [ ] VoiceBank-DEMAND（论文常比）
- [ ] 噪声：DEMAND、Audioset 噪声、室内/键盘/风噪
- [ ] 数据怎么造：干净语音 × 噪声 × SNR 采样（例如 -5~20 dB）+ 轻度混响

### 1.7 压缩：量化 / 剪枝 / 蒸馏（JD 有，且你做过评测）

电话偏模型，仍可能问，因为端侧 NS 一定要小。

- [ ] **量化：** 浮点 → INT8 / INT4；减小体积和带宽，可能掉 PESQ
- [ ] **PTQ：** 训完后校准，数据少、快，精度掉得多
- [ ] **QAT：** 训练中模拟量化，精度更好、更贵
- [ ] **剪枝：** 去不重要权重/通道；结构化剪枝才对推理加速友好
- [ ] **蒸馏：** 大教师 → 小学生；学生模仿教师 logits 或特征
- [ ] 你项目里的接法：做过剪枝、量化后模型行为是否还在（水印场景）；迁移到 NS 就是 **PESQ/STOI 掉多少、模型小多少、RTF 降多少**

**不要说：** 我在端侧用 TFLite 部署过 NS。没做过就说「推理框架可以学，我更熟训练侧和压缩评测」。

## 5. 可能被追问的项目讲法（各 40 秒）

**音频项目（主打）**

> 目标是给生成音频加可验证信息，同时尽量不影响听感。我负责训练和评测：在扩散音频模型上写嵌入和提取流程，用 PESQ、SNR、MOS 看听感，再用压缩、滤波、加噪、重采样看鲁棒性。收获是熟悉时频表示、生成轨迹和音频指标，也习惯同时看「质量」和「可提取/可恢复」。

**视觉项目（证明会训模型 + 压缩）**

> 在 CLIP、BLIP、LLaVA 上做训练和验证，评过微调、剪枝、量化后模型还是否稳定。对我来说，重点是多模态训练管线和鲁棒性实验设计，不是具体业务名词。

**被问「和降噪有什么关系」**

> 增强是恢复干净语音，我做的是在音频表征上写信息并抗失真；共用的是 STFT/时频、听感指标、以及压缩量化后还能否保持性能。差别是目标函数不同，NS 要 SI-SDR/PESQ，我可以按这个重训。
