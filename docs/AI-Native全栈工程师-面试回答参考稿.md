## 前置知识：Transformer、QKV 与注意力（先看再看项目）

CLIP / BLIP / SigLIP / GPT / DiT 都是同一块积木。面试官常从这里起手：「一层里有什么？QKV 是什么？为什么要除以根号 d？」这一节按**能画、能手写、能用检索类比讲人话**准备。项目里的公式见 §3.16，这里把底座讲透。

### 前.1 一句话：Transformer 在干什么

输入是一串向量（token），输出是**同样长度**的一串向量。每个位置的新向量，都融合了序列里（允许看到的）其他位置的信息。没有卷积的局部窗口，也没有 RNN 的逐步隐藏态，靠的是注意力：谁和谁相关，就多看谁。

三种外壳，芯是同一套层：

| 外壳 | 谁在用 | 能不能看后面的 token |
|------|--------|----------------------|
| Encoder-only | BERT、CLIP 文本塔、ViT | 能，双向 |
| Decoder-only | GPT、Llama、多数 LLM | 不能，因果掩码 |
| Encoder–Decoder | 原版翻译 Transformer、T5 | 解码器对自己因果，对编码器交叉注意力 |

**接到岗位：** Agent / RAG 用的 LLM 是 Decoder-only；你项目里的 CLIP 图像塔是 Encoder-only（ViT）。

### 前.2 必须能默画的总图

```
token 编号
   ↓
[嵌入 Embedding]  +  [位置编码]
   ↓
重复 N 次：Transformer 层
   ├─ 多头自注意力（QKV）
   ├─ 残差 + LayerNorm
   ├─ 前馈网络 FFN / MLP
   └─ 残差 + LayerNorm
   ↓
输出隐状态  （分类头 / 语言模型头 / 投影到对比空间）
```

原论文是「先注意力再 Norm」（Post-LN）。现在预训练模型几乎都是 **Pre-LN**：先 Norm 再算子，训练更稳。口述时说「现代实现一般 Pre-LN」即可。

GPT 类还要在注意力上加**下三角掩码**，位置 i 只能看 1…i。

### 前.3 Token、嵌入、位置：进层之前发生了什么

1. **切 token：** 文本用 BPE / SentencePiece 切成子词；图像用 ViT 切成 patch（见前.10）。
2. **查表变成向量：** 词表大小 V、模型维度 d，嵌入矩阵 E 是 V×d。第 i 个 token 的 id 去 E 里取一行，得到 x_i ∈ ℝ^d。
3. **加上位置：** 注意力本身对顺序置换是不变的，必须单独告诉模型「谁在前谁在后」。

常见位置做法：

- **绝对正弦 / 可学习表：** 每个位置一个向量，加到嵌入上。ViT、早期 BERT 常用可学习表。
- **RoPE（旋转位置）：** 把旋转作用在 Q、K 上，点积里自然带相对距离。Llama 系常用。面试说到「相对位置写进 QK 点积」就够。

没有位置编码，把句子打乱，注意力分数集合不变——这就是为什么必须加位置。

### 前.4 一层 Transformer 里到底有哪些模块

以 Pre-LN、隐状态维度 d、序列长 n 为例。输入 X 形状 n×d。

```
X
 │
 ├→ LayerNorm → 多头自注意力 MHA → 输出与 X 相加（残差）
 │
 └→ LayerNorm → FFN（两层线性 + 激活）→ 再与上一支相加
```

公式（和 §3.16.1 同一套，这里拆开讲）：

```
Y = X + MHA(LN(X))
Z = Y + FFN(LN(Y))
```

**FFN：** 每个位置独立，不看邻居。典型是

```
FFN(h) = W2 · act(W1 h + b1) + b2
```

中间维度常是 4d（或 Llama 的门控 FFN）。激活：GELU / SiLU。直观上注意力负责「和谁说话」，FFN 负责「在每个位置自己做非线性加工」。参数量上 FFN 往往比注意力还大。

**残差：** 输出 = 输入 + 变换。梯度可以抄近道回去，几十上百层才训得动。  
**LayerNorm：** 对**每个 token 自己的 d 维**做标准化（不像 BatchNorm 沿 batch）。公式见附录 A.2。

面试默写顺序：**LN → 注意力 → 残差 → LN → FFN → 残差。**

### 前.5 Q、K、V 是什么（核心，用检索讲）

同一段输入 X（n×d），乘三个不同的矩阵，得到三组向量：

```
Q = X W_Q      形状 n × d_k     「我在问什么」
K = X W_K      形状 n × d_k     「我能被怎样检索」
V = X W_V      形状 n × d_v     「匹配上之后我交出什么」
```

W_Q、W_K、W_V 是学出来的，不是手工规则。

**检索类比（强烈建议用这个讲）：**

| 符号 | 像什么 | 一句话 |
|------|--------|--------|
| Q (Query) | 搜索框里的问题 | 当前 token 想从别人那里拿什么信息 |
| K (Key) | 每篇文档的索引标题 | 每个 token 对外展示的「标签」，用来和 Q 比相似度 |
| V (Value) | 文档正文 | 真要混合进当前表示的内容 |

所以不是「Q 重要、V 不重要」。**相似度在 Q 和 K 之间算，真正加权求和的是 V。** 某个位置和你很像（QK 大），就多把它的 V 加进来。

**为什么要三套而不是一套？** 若 Q=K=V=X，每个位置只能用「自己长什么样」同时当问题和当内容，表达力差。拆开后：我可以「看起来不像你（K 不同），但把另一路信息（V）传给你」。

**Self-Attention（自注意力）：** Q、K、V 都来自**同一条**序列。句子内部互相看，或图的 patch 互相看。CLIP 的 ViT、GPT 的每一层都是这个。

**Cross-Attention（交叉注意力）：** Q 来自 A，K 和 V 来自 B。

```
Q = X_A W_Q
K = X_B W_K
V = X_B W_V
```

A 在「读」B。BLIP 的图文融合、扩散 UNet 里文本条件、Encoder–Decoder 翻译，都是交叉注意力。LLaVA 则常常把视觉特征当 token **拼进** LLM，主要靠自注意力融合，不一定单独做 cross-attn。

**接到水印 / LoRA：** 微调常动 W_Q、W_V（LoRA 默认也常挂这两处）。你在 CLIP 上加水印，改的就是这些投影和 FFN，让触发图文对在注意力对齐上走出可验证方向。

### 前.6 缩放点积注意力：五步手算

对一组头（先别管多头）：

```
Attention(Q, K, V) = softmax( (Q K^T) / √(d_k) ) V
```

逐步：

1. **打分：** S = Q K^T，形状 n×n。S_{ij} = q_i · k_j，表示位置 i 对位置 j 有多关注。
2. **缩放：** 除以 √(d_k)。d_k 大时点积方差大约是 d_k，softmax 会挤成 one-hot、梯度没了。除根号后方差回到约 1。
3. **掩码（可选）：** 不该看的位置（未来 token、padding）把分数设成 -∞，softmax 后就是 0。
4. **softmax（按行）：** 每一行变成一组和为 1 的权重。α_{ij} 就是 i 看 j 的比例。
5. **加权求和：** 第 i 行的输出 o_i = ∑_j α_{ij} v_j。还是 d_v 维。

**复杂度：** n 个位置两两打分，时间与显存都是 O(n² · d)。这就是长文本贵、ViT patch 变小（n 变大）会爆的原因。KV cache（vLLM）则是生成时把已经算过的 K、V 存下来，避免每步从头算整段。

**极小例子（口述）：** 两个 token「猫」「坐」。算「坐」的新向量时，Q_坐 去点 K_猫 和 K_坐，得到两个分数，softmax 成 0.7 / 0.3，则输出 ≈ 0.7 V_猫 + 0.3 V_坐——「坐」这个位置掺进了大量「猫」的信息。

### 前.7 多头注意力（Multi-Head）

单头等于只用一种相似度。多头把 d 拆成 h 份，每头自己的 W_i^Q、W_i^K、W_i^V，d_k = d / h（常见 64）。

```
head_i = Attention(X W_i^Q, X W_i^K, X W_i^V)
MHA(X) = Concat(head_1, …, head_h) W_O
```

最后 W_O 把拼起来的 h·d_v 投回 d 维。

**人话：** 有的头更像在对齐语法（谁修饰谁），有的更像对齐物体共现。不必把每个头的语义讲死，说「多组子空间、多种关系」即可。

**参数：** 全部头的 QKV + W_O，总量大约仍是 4 d² 量级（和「一个大头再投影」同阶），但实现上更稳、效果更好。

结构化剪枝若按头剪：剪掉的是某组关系。你的水印若碰巧绑在少数头上，剪头可能既掉精度又掉检测率——评测里要报这个。

### 前.8 因果掩码、双向、padding

```
双向（BERT / CLIP 文本 / ViT）：
  每个位置能看整句 / 整图，适合理解、对齐。

因果（GPT）：
  位置 i 只能看 ≤ i，才能用「下一个词」当监督，否则作弊。

Padding 掩码：
  短句补齐的空位分数打成 -∞，不要让空白 token 污染平均。
```

**生成时：** 第一步 prefill 把提示一次性编成 K、V；之后每步只出一个新 token，它的 Q 去点**缓存里所有历史 K**，再取出对应 V。这就是 KV cache，也是 vLLM PagedAttention 管的对象（§10.3）。

### 前.9 Softmax 温度（和 CLIP 的 τ 不是同一个旋钮，但亲戚）

注意力内部：缩放已经用 √(d_k)。若再把分数除以 T，T→0 更尖、更只看最大的 Key。

CLIP 的温度 τ 是**对比损失里的**，作用在图文相似度上，不是注意力公式里的那个。别混。但直觉同类：温度小 → 分布尖 → 难负样本更狠。

### 前.10 ViT：图像如何变成「句子」

CNN 用局部卷积堆出特征图。ViT 直接把图当序列：

1. 图 H×W，patch 边长 P，得到 n = HW/P² 个块。
2. 每块展平，线性映射到 d 维（patch embedding）。
3. 加上 2D 位置（或 1D 可学习位置）。
4. 往往再在序列前插一个 `[CLS]` token，最后用它的输出当整图向量（CLIP 图像塔常用；也有人 mean-pool 所有 patch）。
5. 后面就是普通 Encoder Transformer。

**和 CLIP 文本塔：** 一边是 patch 序列，一边是 BPE 序列，两边各叠 Transformer，最后投影到同一维做 InfoNCE（§3.16.2）。

**追问：** P 从 16 改 8，n 变成 4 倍，注意力 O(n²) 变成 16 倍。高分辨率多图推理贵，就是这个。

### 前.11 和 CNN / RNN 比，面试各用一句

- **vs RNN：** 注意力一步看全局，长距离依赖不靠一步步传；RNN 不能并行到整个序列，Transformer 训练可并行。代价是 n²。
- **vs CNN：** 卷积归纳偏置强（局部、平移），小数据友好；Transformer 要更大的数据/预训练，但上限高，图文统一成 token 更好接 LLM。

### 前.12 常见超参叫得出含义

| 符号 | 含义 | 量级直觉 |
|------|------|----------|
| n / seq_len | 序列长度 | 文本 2k–128k；ViT 196（224/16²） |
| d / d_model / hidden | 残差流维度 | 768 / 1024 / 4096 |
| h / n_heads | 头数 | 12、32；d 必须能整除 |
| d_k | 每头 QK 维 | 常 = d/h，如 64 |
| d_ff | FFN 中间维 | 常 4d |
| L / n_layers | 层数 | CLIP ViT-B 12；7B LLM 约 32 |

粗算一层注意力线性部分：W_QKV 约 3 d²，W_O 约 d²，FFN 约 2·d·d_ff。层数一乘，就是「7B、13B」从哪来。

### 前.13 60 秒口述（背这段）

Transformer 把 token 序列变成同长的新序列。每一层先 LayerNorm，再多头自注意力，残差加回去；再 LayerNorm + FFN，再残差。注意力里输入乘出 Q、K、V：Q 和 K 做点积得到谁该看谁，除以 √(d_k) 再 softmax，用这些权重去加和 V。多头是把这个过程在不同子空间做若干次再拼回来。GPT 加因果掩码所以能做语言模型；CLIP 的图和文本各用一个双向 Encoder，最后对齐。我做 VLM 水印，就是在这些塔的权重上微调，让特定图文条件走出可验证行为。

### 前.14 高频追问速答

**Q 和 K 能不能共用一个矩阵？** 能，早期有变体；主流拆开更强。V 更不该和 Q 绑死。  
**d_k 和 d 必须相等吗？** 不必，但实现上常 d_k=d/h。  
**为什么 n²？** n 个 Q 每个都要和 n 个 K 打分。  
**Dropout 加在哪？** 注意力权重或残差支路，防止过拟合；推理关掉。  
**GQA / MQA 是什么？** 多头的 Q 仍多组，K/V 头更少，用来减 KV cache。vLLM 服务大模型时常遇到。知道即可。  
**和我项目的接口：** 图像进 ViT Encoder；文本进 Transformer Encoder 或自回归 Decoder；BLIP 融合用交叉注意力；LoRA 挂 W_Q/W_V；剪头攻击等于拆多头。

看完本节再看 §3.16：那里的 MSA、LN、InfoNCE 都建立在 QKV 这一层上。

## 3. 项目一：VLM 多模态全过程水印（必问，准备最深）

2024.08–2025.08｜2025 届全国大学生信息安全作品赛全国一等奖｜论文审稿中

### 3.1 一分钟介绍

VLM 很贵，模型本身是知识产权；生成图文又会再分发，需要溯源。已有方案常见两个坑：只做单模态，探测一侧就能绕；图文条件没协同，可验证性和主任务会打架。

我做的是全过程：训练侧在 CLIP / BLIP / SigLIP 上做跨模态水印，解决模型确权；内容侧用 DWT 可逆图像水印；生成侧在文本里嵌水印。数据用了 Caltech101、DTD、EuroSAT、OxfordPets。评测看三件事：主任务精度、水印能否检出、微调/结构化剪枝后还在不在。我负责微调与水印训练管线、对比和鲁棒性评测，竞赛阶段指导系统与评测脚本，并独立把方案整理成论文。

### 3.2 「全过程」到底是什么

三层，不要混：

1. **训练侧 / 模型确权：** 带触发的图文对参与训练，使模型在特定「提示 + 图像」条件下给出可验证行为。证明「这是我们训出来的模型」。
2. **内容侧 / 输入图像溯源：** DWT 可逆水印嵌在图像里，载体可还原，用于图从哪来。
3. **生成侧 / 输出文本溯源：** 生成时在 token 分布上做可统计检测的偏置，事后能抽或做假设检验。

一句话：模型是谁的、图从哪来、字是谁生成的，三条链路都覆盖。

### 3.3 为什么单模态会失效

只在图像藏：攻击者看像素统计、或只用文本接口，图像水印用不上。  
只在文本藏：换解码参数、改写、翻译、换提示，文本信号容易没。  
图文各藏各的、不协同：触发对不齐，主任务掉点还不好检。

所以目标是：**可验证、难单侧暴露、主任务尽量不动。** 这三个互相打架，要用触发设计、损失权重和评测一起压。

### 3.4 CLIP / BLIP / SigLIP 怎么用、有何不同

| 模型 | 我怎么理解 | 水印怎么挂 |
|------|------------|------------|
| CLIP | 图文对比学习，拉近配对、推开不配对 | 水印样本作为特殊配对，或在对齐空间加可分信号；适合「同一触发在两模态都被认出」 |
| BLIP | ITC + ITM + 语言模型，既能匹配又能生成 | 更适合提示–图像双条件：图像条件 + 文本提示同时满足才走水印路径 |
| SigLIP | sigmoid 损失，不依赖大批负样本 | 训练更稳，触发比例、难度要按正负样本定义重调，不能照搬 CLIP 的温度和负样本逻辑 |

补一句：我不是只换 backbone 刷分，而是验证跨模态水印在不同对齐目标和生成头上是否都成立。

### 3.5 提示–图像双条件触发

单条件太容易误触发或被单侧探测。双条件是：只有**特定触发图 + 特定提示**同时出现，才稳定走出水印应答；缺一侧，行为接近正常模型。

这样：

- 验证者两边都有，能确权；
- 攻击者只拿到图或只拿到提示，不容易完成提取，也不容易在干净集上误检。

实现上就是控制触发样本占比、触发强度，以及干净样本上的一致性正则，避免模型「一看到怪图就乱说话」。

### 3.6 损失和主任务折中

典型三项（按你代码改名字）：

- 主任务损失：分类、检索或图文匹配
- 水印损失：触发样本上要能检出 / 走出指定行为
- 隐蔽性约束：干净样本上尽量和原模型一致

权重是扫出来的，不是拍的。汇报顺序：**先报主任务掉了多少，再报检测成功率，再报攻击后还剩多少。** 若某组检测 99% 但主任务崩了，这组不能当主结果。

### 3.7 攻击评测怎么做

对应真实威胁「拿到模型去继续训、去压缩结构」：

- **微调去除：** 干净数据上全参或 LoRA 再训。看学率、轮数、数据占比。能说清：轻量微调通常去不掉；足够多干净数据 + 足够步数会削弱，但主任务也在变，这是攻击成本。
- **结构化剪枝：** 按头、通道或层剪。随机剪和按重要性剪都要做。若剪到检测崩溃但精度也垮，说明水印和有效能力绑在一起，这是优点不是缺点。

还会被问蒸馏、量化、改 prompt。答：蒸馏/量化在系统评测里按算力做了或列为后续；prompt 攻击主要打生成侧文本水印，训练侧双条件相对更稳。没做的就说没做，不要编。

### 3.8 DWT 可逆图像水印

为什么用 DWT：能量集中在低频，高频改动相对不显眼；小波可逆，满足「能提取还能恢复原图」，适合确权后还要原图的场景。

嵌在哪：常见是中频子带，在鲁棒和失真之间折中。低频太影响观感，高频太不鲁棒。

和 LSB 的差别：LSB 不可逆、不抗压缩；DWT 可逆方案走变换域，用 MSE / PSNR / SSIM 报告失真。可逆不等于无限鲁棒，强 JPEG 后提取会变差，所以它负责内容侧，不替代模型侧。

### 3.9 文本水印

和 Kirchenbauer 那类方法同一思路：把词表分成偏好集合，生成时给 logit 加偏置，检测时看实际 token 是否显著偏向该集合。

在 VLM 里挂在语言头的解码阶段。评测用检测成功率和困惑度：PPL 涨太多说明伤了流畅度。对改写、截断、翻译不鲁棒，所以只作为生成侧一层，不单独扛确权。

### 3.10 数据和指标

数据：Caltech101、DTD、EuroSAT、OxfordPets，覆盖物体、纹理、遥感、细粒度，避免水印只在单一视觉域有效。

指标：

- 主任务：准确率 / 检索指标
- 水印：成功率、检测 TPR/FPR
- 图像：MSE / PSNR / SSIM
- 文本：PPL

汇报模板（把论文/海报真数填进去）：

> 干净模型准确率 X，加水印后 Y，相对掉 Z 个点；触发检测成功率 A；微调/剪枝后检测还剩 B；图像 PSNR C；文本 PPL 从 D 到 E。

### 3.16 原理与公式（VLM / CLIP / BLIP / SigLIP / 水印损失 / DWT / 文本水印）

面试要能**手写关键式子 + 用一句话说人话**。下面按「模型在干什么 → 公式 → 和你项目怎么接」写。

#### 3.16.1 ViT 图像塔（CLIP/BLIP/SigLIP 共用）

QKV、一层模块、因果/双向掩码见上文**前置知识**。这里只接到图像。

把 H×W 图切成 P×P 的 patch，得到 N=HW/P^2 个块，每个块展平后线性投影成 d 维，再加位置编码和可选 `[CLS]`：

```
z_0 = [x_{cls}; x_1 W_e; …; x_N W_e] + E_{pos}
```

每个 Transformer 层：

```
z'_ℓ = MSA(LN(z_{ℓ-1})) + z_{ℓ-1}
```

```
z_ℓ = MLP(LN(z'_ℓ)) + z'_ℓ
```

**人话：** 图像先切块再当 token 序列做自注意力，`[CLS]` 或池化后的向量就是图像嵌入。  
**追问 patch 变小：** N 变大，注意力是 O(N^2)，算力和显存涨很快。

自注意力（必须能手写）：

```
Attention(Q, K, V) = softmax(QK^T / √(d_k))V
```

多头：各头用不同 W_i^Q, W_i^K, W_i^V，拼起来再乘 W^O。  
**为什么除 √(d_k)：** 点积方差随维度变大，softmax 会饱和成 one-hot，梯度消失。

#### 3.16.2 CLIP：双塔 + 对称 InfoNCE

图像编码器 f(·)、文本编码器 g(·)，输出都做 ℓ_2 归一化。batch 内相似度（温度 τ>0）：

```
s_{ij} = f(x_i)^T g(t_j) / τ
```

图到文、文到图两条交叉熵（正样本是对角 i=j，其余 N-1 个是负样本）：

```
ℒ_{I2T} = -1/N ∑_{i=1}^{N} log(exp(s_{ii}) / (∑_{j=1}^{N} exp(s_{ij})))
```

```
ℒ_{T2I} = -1/N ∑_{i=1}^{N} log(exp(s_{ii}) / (∑_{j=1}^{N} exp(s_{ji})))
```

```
ℒ_{CLIP} = 1/2 (ℒ_{I2T} + ℒ_{T2I})
```

Zero-shot 分类：把类别名填进 prompt（如 `a photo of a {label}`），用 f(x)^T g(t_c) 取最大。

**τ 过小：** softmax 极尖，难负样本梯度大，训练不稳。  
**τ 过大：** 分布太平，拉不开正负对。  
**为什么要大 batch：** 负样本都在当前 batch 里，N 越大对比越有信息。

**接到水印：** 触发图文对当作额外正对，或在对齐空间加「可分方向」。验证时看触发对的相似度/检索是否走出可验证模式。主任务仍是 InfoNCE 或下游分类精度。

#### 3.16.3 BLIP：ITC + ITM + LM（多任务）

BLIP 不是纯双塔。图像进 ViT，文本进 BERT 系编码器；有单模态对比，也有跨模态融合。

**(1) ITC（Image-Text Contrastive）**  
和 CLIP 类似，常用单模态 `[CLS]` 做对比，损失仍是 InfoNCE。作用：先把图文拉到可比较的空间。

**(2) ITM（Image-Text Matching）**  
把图特征和文本送进跨模态编码器，做二分类「配对 / 不配对」：

```
ℒ_{ITM} = CE(h_{itm}(Fusion(v, t)), y∈{0, 1})
```

负样本常从对比相似度里挖难负例，不是随机抽。作用：细粒度匹配，比纯对比更能判断「这图配不配这句」。

**(3) LM（Language Modeling / Caption）**  
因果语言建模，图作为条件生成描述：

```
ℒ_{LM} = -∑_{k} log p_θ(w_k | w_{<k}, visual)
```

总损失通常是三项加权：

```
ℒ_{BLIP} = λ_1 ℒ_{ITC} + λ_2 ℒ_{ITM} + λ_3 ℒ_{LM}
```

**人话：** CLIP 只会「像不像」；BLIP 还会「是不是这一对」以及「看图说话」。  
**接到双条件触发：** 图像条件走视觉侧，提示走文本侧，两者同时满足才让 ITM/LM 走出水印应答；缺一侧则 ℒ_{LM}/ℒ_{ITM} 仍按干净数据约束。这是 BLIP 比 CLIP 更适合双条件的原因。

#### 3.16.4 SigLIP：sigmoid 损失（没有 softmax 归一化）

对归一化嵌入 x_i, y_j，可学习温度 t 和偏置 b：

```
z_{ij} = t·x_i^T y_j + b, ε_{ij} = { +1 if i=j; -1 if i≠j }
```

```
ℒ_{SigLIP} = -1/N ∑_{i=1}^{N} ∑_{j=1}^{N} log σ(ε_{ij} z_{ij})
```

其中 σ(u)=1/(1+e^{-u})。正对要 z_{ii} 大，负对要 z_{ij} 小。

**和 CLIP 的本质差别：** CLIP 的分母是 batch 内所有负样本的 softmax，负样本互相耦合；SigLIP 每个 pair 独立过 sigmoid，**不依赖「这一批里有哪些负样本」**，更适合小 batch、异步、大规模。  
**接到水印：** 触发比例、难负样本定义不能照搬 CLIP 的温度逻辑；偏置 b 会管整体正负比例，触发样本太少时要盯 b 和正对权重，否则水印梯度被海量负对淹没。

#### 3.16.5 训练侧水印：通用损失形态（按你论文替换符号）

公开后门/指纹文献的共同骨架（口述用这个，细节用自己符号）：

```
ℒ = ℒ_{task}
 + λ_w ℒ_{wm}(x^{t}, t^{t})
 + λ_c ℒ_{clean}(x, t)
```

- ℒ_{task}：原对比 / ITC / 分类，保主任务。
- ℒ_{wm}：仅在触发图 x^t 与触发提示 t^t **同时出现**时，强迫可验证行为（指定相似度、指定 ITM 标签、指定生成短语等）。
- ℒ_{clean}：干净样本上约束与原模型一致，常用 KL：

```
ℒ_{clean} = KL(p_{θ}(·| x, t) || p_{θ_0}(·| x, t))
```

或嵌入空间的 ||f_θ(x)-f_{θ_0}(x)||_2^2。

双条件形式化（防单侧暴露）：

```
𝔼[1[Detect(x, t)]]
≈
{ 高 if x∈𝒯_v ∧ t∈𝒯_t; 低 if 只中一侧或都不中 }
```

**三种水印别混：**

| 类型 | 藏在哪 | 要证明什么 |
|------|--------|------------|
| 模型后门/指纹 | 参数 / 触发行为 | 这套权重是我的 |
| 内容水印 | 像素/变换域 | 这张图从哪来 |
| 生成水印 | 解码分布 | 这段字是我的模型生成的 |

#### 3.16.6 LoRA（微调水印和业务微调都会问）

冻结原权重 W_0∈ℝ^{d× k}，只训低秩增量：

```
W = W_0 + α / rBA, B∈ℝ^{d× r}, A∈ℝ^{r× k}, r≪ min(d, k)
```

可训参数量约 r(d+k)，不是 dk。常插在注意力的 W_Q, W_V（或再加上 W_K, W_O）。

**QLoRA：** 把 W_0 量化成 4bit，再在其上挂 LoRA，显存主要省在基座。  
**接到攻击：** 「用 LoRA 在干净数据上再训」是去除攻击的一种；若水印只在很小的低秩方向上，可能更容易被洗掉，所以你们若做全参水印微调，要能解释：信号和主表示绑得更紧，去水印代价是主任务也变。

#### 3.16.7 DWT 可逆图像水印

二维离散小波：对行、列依次做低通 h_L、高通 h_H，一层得到四个子带 {LL, LH, HL, HH}。Haar 一维示意（未归一化）：

```
s[i] = (x[2i] + x[2i + 1]) / √(2), d[i] = (x[2i]-x[2i + 1]) / √(2)
```

正变换和逆变换都是线性可逆（正交小波时能量守恒），所以可以「提取后再精确重建原图」。

嵌入通常改中频（LH/HL）：低频 LL 改了块效应/亮度明显，高频 HH 不抗 JPEG。失真指标：

```
MSE = 1/HW ∑_{i, j}(I_{ij}-Î_{ij})^2
```

```
PSNR = 10log_{10}MAX^2 / MSE
(8bit 图MAX = 255)
```

SSIM 比 PSNR 更接近结构相似度，由亮度、对比度、结构三项相乘。  
**口述：** 可逆 ≠ 抗压缩。DWT 负责内容侧溯源；训练侧确权不靠它。

#### 3.16.8 生成文本水印（Kirchenbauer 型）

词表 V 按密钥分成绿名单 G（占比 γ）和红名单。对当前 logit ℓ，绿词加偏置 δ：

```
ℓ̂_w = ℓ_w + δ·1[w∈ G]
```

```
p(w) = softmax(ℓ̂)_w
```

检测：长度为 T 的文本里绿词个数 g，零假设「没有水印」下 gsimBin(T, γ)，用 z 分数

```
z = (g-γ T) / (√(Tγ(1-γ)))
```

z 超过阈值则判为带水印。困惑度：

```
PPL = exp(-1/T ∑_{k=1}^{T} log p_{θ}(w_k | w_{<k}))
```

PPL 升高 = 更不像自然文本。δ 越大越好检测、越伤流畅度。改写/翻译会打乱绿词统计，所以文本水印只能当生成侧一层。

#### 3.16.9 主任务与检测指标

分类准确率：Acc=1/N ∑1[ŷ_i=y_i]。  
检测：TPR = 有水印且检出，FPR = 干净却报有。阈值要同时报这俩，只报成功率会被喷。  
剪枝：结构化剪掉头/通道后，主任务掉点 DeltaAcc 和水印 DeltaTPR 要一起看——两者一起崩，说明信号绑在有效通道上。

## 4. 项目二：生成音频版权与溯源水印

2025.08–2026.08｜2026 届全国大学生信息安全作品赛全国一等奖｜论文投稿中

### 4.1 一分钟介绍

生成音频已经在内容生产里用，合成音再分发后很难证明来源。事后把水印贴到波形上，和生成过程脱节，压缩、重采样后容易没；有些生成式方法还不稳定恢复多比特。

我在 AudioLDM、DiffWave、PriorGrad 上做**生成过程中写入、事后解码验证**。数据含 LibriSpeech。评测有效性、听感（SNR、PESQ、MOS），以及压缩、重采样、裁剪、滤波、噪声和去水印攻击。我负责嵌入–提取管线、失真与去除评测，竞赛阶段指导方案和文档，并写了问题动机与方法章节。

### 4.2 为什么事后嵌入不够

事后嵌入面对的是已经定型的波形，攻击者做 MP3、重采样、裁剪，信号在感知不敏感带，很容易被当噪声去掉。它也无法回答「是不是这个生成器产的」。我们把水印放进生成过程，让「能生成这段音频」和「带我们的身份」绑在一起。

### 4.3 写在扩散的哪一步

按真实实现只保留一种，口头要坚定。三种标准说法：

**说法 A（初始噪声 / 种子）：** 用密钥把身份编进初始噪声。实现简单，但后面去噪长，多比特恢复不稳定，裁剪后同步难。

**说法 B（latent 条件，适合 AudioLDM）：** AudioLDM 在 mel/latent 上扩散，水印加在 latent 或条件向量，再经 vocoder。和模型结构贴合，听感与鲁棒较好折中。

**说法 C（逐步去噪调制）：** 每步或每隔几步对预测噪声/均值做轻量调制，用匹配滤波器或专用解码器抽。容量和鲁棒更好，训练和解码更重。

推荐主讲 B 或 C，并补：选这一层是因为要在 vocoder 之前把信号放到语义/声学表示里，比贴在最终波形更抗常见后处理。

### 4.4 三个生成模型差异

- **AudioLDM：** 文本/条件 → latent 扩散 → mel → vocoder 成波。水印重点在 latent/mel，vocoder 也是失真源，评测必须含完整合成。
- **DiffWave：** 波形上扩散，路径短、控制直接，听感对扰动更敏感。
- **PriorGrad：** 数据自适应先验，收敛更好；水印要适配非标准高斯先验，不能当普通 DDPM 复制。

做三个不是刷名，是证明「生成中写入」不绑死某一种扩散实现。

### 4.5 多比特如何恢复、裁剪怎么同步

多比特要同时解决容量、误码、同步：

- 载荷：身份 ID 或短哈希，不是长文本。
- 编码：重复码 / BCH 等，换鲁棒不换大容量。
- 同步：裁剪会丢对齐。可用前导序列、分块重复嵌入，或盲检测只回答「有没有我们的水印」；确权演示以盲检测 + 短 ID 为主。

没做精确到任意裁剪都恢复满比特，就明确说：强裁剪下先保检出，再保完整解码。

### 4.6 听感指标

- **SNR：** 信号失真，必要但不等于好听。
- **PESQ：** 语音感知质量，比 SNR 更接近听感。准备前后对比数字。
- **MOS：** 人工分，竞赛演示很有用；要说明样本量和是否盲听。

口径：水印后 PESQ 仍在可用语音范围，MOS 不明显劣于无水印；若某攻击 PESQ 还行但提取崩了，说明攻击打的是同步/频带，不是把声音毁掉。

### 4.7 攻击矩阵

| 攻击 | 它在模拟什么 | 通常结果怎么说 |
|------|----------------|----------------|
| 压缩（MP3 等） | 平台转码 | 频带损失，变换域/latent 方案好于事后 LSB |
| 重采样 | 格式转换 | 要抗插值；写入若绑绝对采样点会失败 |
| 裁剪 | 切片转发 | 看同步；分块重复更稳 |
| 滤波 | 均衡、去噪 | 伤窄带嵌入 |
| 加噪 | 信道/录制 | 看强度；过强听感先坏 |
| 去水印 | 针对已知算法 | 要报「去掉的代价」：PESQ 崩了还是模型还要重训 |

最伤的往往是「压缩 + 裁剪」组合，或针对解码器的专用去除。讲实验里最差的那一个，比讲「都很鲁棒」可信。

### 4.8 迁移到图视频生成

生成式水印的工程问题和 ComfyUI / 图视频落地是一类的：插入点在 pipeline 哪一层、对质量指标的影响、后处理还能不能抽。你们若做图视频，我可以把「生成节点 + 质量回归 + 攻击集」搬过去，先做可复现工作流，再谈水印节点。

### 4.9 本项目必要知识点

- DDPM / DDIM：前向加噪、反向去噪、条件生成
- mel 谱、vocoder、latent diffusion
- 感知指标 vs 信号指标
- 同步水印 vs 盲提取
- 鲁棒性和不可感知性的权衡

### 4.10 原理与公式（DDPM / DDIM / CFG / AudioLDM / DiffWave / PriorGrad / 听感指标）

#### 4.10.1 DDPM 前向：一步步加高斯噪声

给定干净样本 x_0（波形、mel 或 latent），噪声日程 β_t∈(0, 1)，α_t=1-β_t，α̅_t=∏_{s=1}^{t}α_s：

```
q(x_t | x_{t-1}) = 𝒩(√(α_t) x_{t-1}, β_t I)
```

可一步到位（面试必写）：

```
x_t = √(α̅_t) x_0 + √(1-α̅_t) ε, ε∼𝒩(0, I)
```

t=0 接近数据，t=T 接近纯噪声。

#### 4.10.2 反向：网络预测噪声，变分目标简化成 MSE

反向每步高斯：

```
p_θ(x_{t-1} | x_t) = 𝒩(μ_θ(x_t, t), σ_t^2 I)
```

实践中网络 ε_θ(x_t, t) 直接预测 ε，训练目标（简化）：

```
ℒ_{simple} = 𝔼_{x_0, ε, t}||ε-ε_θ(x_t, t)||_2^2
```

由 ε_θ 可还原 x̂_0：

```
x̂_0 = (x_t-√(1-α̅_t) ε_θ(x_t, t)) / √(α̅_t)
```

**人话：** 前向把数据搅成噪声，网络学会从带噪输入里把那团噪声减回去。

#### 4.10.3 DDIM：可跳步、可少随机

DDIM 把反向改成非马尔可夫，用同一套 ε_θ，但更新是

```
x_{t-1} = √(α̅_{t-1}) x̂_0
 + √(1-α̅_{t-1}-σ_t^2) ε_θ(x_t, t)
 + σ_tε
```

σ_t=0 时变成确定性采样：同样子种子可复现，步数可从 1000 收到 50。代价是多样性下降、某些步数下质量变差。竞赛演示常用 DDIM 换速度。

#### 4.10.4 条件生成与 CFG

条件 c（文本、类、说话人）进入 U-Net/DiT，常见两种：cross-attention 或 AdaLN。Classifier-free guidance：同时训有条件和无条件，采样时

```
ε̃ = ε_θ(x_t, ∅) + s(ε_θ(x_t, c)-ε_θ(x_t, ∅))
```

s>1 更听文本、更「猛」，过大则失真、过饱和。水印若写在条件支路，CFG 强度会改变信号幅度，评测要扫 s。

#### 4.10.5 AudioLDM：mel 上的 latent 扩散

流水线：

1. 波形 → 对数 mel 谱 X。
2. VAE 压到 latent z=ℰ(X)，解码 X̂=𝒟(z)。
3. 在 z 上做条件扩散（文本常用 CLAP 或 FLAN-T5 嵌入作 c）。
4. X̂ → vocoder（HiFi-GAN 一类）→ 波形。

VAE 训练带重构 + KL：

```
ℒ_{VAE} = ||X-𝒟(ℰ(X))||^2 + β KL(q(z|X) || 𝒩(0, I))
```

**水印插入点（按你实现只讲一种）：**

- 改初始 z_T 或种子：实现简单，经很多步去噪 + vocoder 后多比特易糊。
- 改条件 c 或中间 z_t：和模型结构同尺度，鲁棒/听感较易折中。
- 每步调制 ε_θ 或 μ_θ：容量更好，要训/配解码器。

vocoder 本身是失真源，**评测必须跑完整「latent → mel → 波」**，不能只在 mel 上报告 SNR。

#### 4.10.6 DiffWave：波形上的离散扩散

直接在 x∈ℝ^L 波形上做 q(x_t|x_0)，网络多为带膨胀卷积的 WaveNet 式 ε_θ。没有 VAE，路径短、控制直接，对幅度扰动更敏感。条件可以是 mel（声码器用法）或更弱的全局条件。水印写在波形噪声里会更「听得见」，强度要更小。

#### 4.10.7 PriorGrad：数据自适应先验

标准 DDPM 的 x_T∼𝒩(0, I)。PriorGrad 用数据相关对角协方差 Σ(c)（由能量或 mel 估计）：

```
q(x_t | x_0, c) = 𝒩(√(α̅_t) x_0, (1-α̅_t)Σ(c))
```

网络在该先验下学去噪，收敛往往更快。  
**接到水印：** 不能把「标准高斯扰动」直接抄过来；嵌入和解码都要在 Σ(c)^{1/2} 的尺度里做，否则能量大的频带和水印幅度对不齐。

#### 4.10.8 生成中写入的通用形态

把水印比特 m（密钥派生）看成对轨迹的轻量干预。例如逐步调制：

```
ε_θ^{(w)}(x_t, t, c) = ε_θ(x_t, t, c) + η·φ(m, t)
```

η 小 → 听感好、难提取；η 大 → 反。解码器 D 做相关或假设检验：

```
m̂ = D(x̃), x̃ = 𝒜(x)
```

𝒜 是压缩/重采样/裁剪等攻击。同步：裁剪破坏对齐时，用重复嵌入或前导序列；或退化为盲检测「有/无」而不恢复满比特。

#### 4.10.9 听感与误差公式

信号功率 P_s、误差 e=x̂-x：

```
SNR = 10log_{10}||x||_2^2 / ||e||_2^2
```

PESQ：ITU 感知模型，输出约 -0.5∼ 4.5，专门为语音设计，**不是**通用音乐指标。  
MOS：人打 1–5 分，要报样本量和是否盲听。  
**坑：** SNR 高仍可能有可闻谐波；PESQ 高不等于水印不可感知。三个都要，且攻击组要同时看提取率和听感——攻击把声音毁了再去不掉水印，没有意义。

## 5. 项目三：CA-QIM（GlobeCom 一作）

2022.12–2023.04｜CCF C 会议 GlobeCom，第一作者

这个和 JD 最远，但能证明能建模、能写论文。**讲 3 分钟，不要展开成讲座。**

### 5.1 两分钟版

物理层隐写，比如 ECG、电子病历，更看重失真，不看重把容量做很大。经典 QIM、MD-QIM 默认消息均匀。但 LDPC 等真实比特流往往 0 很多。均匀假设会让量化器做很多没必要的移动，透明性不够。

CA-QIM：先统计宿主陪集和消息的共现，重映射码本，让更常见的消息对应「很多点本来就在、不用动」的区域；必须动的点推到 Voronoi 边界，相当于最小移动。我还推导了非均匀消息下的 MSE 上界，在 Z / A2 / D4 / E8 格上验证。bit 0 占比 0.9 时，E8 上 MSE：QIM 0.0457，MD-QIM 0.0271，CA-QIM 0.0203，PSNR 64.08 dB。我是一作，实验图表和正文都是我完成的，后来也接到密文域隐写系统里。

### 5.2 用大白话讲 QIM

把宿主看成数轴或格点上的点。消息 0/1 对应两套量化码本。嵌入就是把点推到对应码本的最近码字；提取看它离哪套码本更近。移动越小，失真越小、越难被听见看见。

MD-QIM 是在多维格上做，利用更好的球堆积，同样信息下平均移动更小。

### 5.3 为什么非均匀要重映射

消息 0 占 90% 时，码本还按 50/50 摆，等于一半「好位置」分给很少出现的 1，大量宿主为了表示 0 还得挪。共现统计后：高频消息占用更大、更近的区域，多数点零移动就能表示目标比特，MSE 自然下来。

### 5.4 格、Voronoi、陪集（能说清即可）

- **格：** 离散周期点阵，Z 是整数格，E8 是 8 维高密度格。
- **Voronoi：** 离该格点比离其他格点更近的区域，量化就是投到胞腔中心。
- **陪集：** 格的平移副本，QIM 用不同陪集代表不同消息。
- **E8 更好：** 同样维度下球堆积更密，量化误差更小。所以 E8 上三组 MSE 都更有说服力。

MSE 上界：在给定消息分布和码本下，每个胞腔内的最大/平均平方误差可以积分或按格的二阶矩界出来。面试说「按胞腔二次矩和消息概率加权」，不要现场推整页公式。

### 5.5 这个项目和岗位的关系

它证明我能把统计假设写成可实现算法，并完成理论和实验。日常开发用不到 E8，但「针对真实数据分布改量化/编码策略」和「给模型效果做可证明的指标」是通用的。点到为止。

**踩坑：** 不要把 CA-QIM 讲成深度学习。它是信号处理 + 格理论。

### 5.6 原理与公式（QIM / MD-QIM / 格 / CA-QIM / MSE 界）

#### 5.6.1 一维 QIM（Chen & Wornell）

量化步长 Δ。消息 m∈{0, 1} 对应两套交错码本，例如：

```
Λ_0 = Δℤ, Λ_1 = Δℤ + Δ / 2
```

嵌入：把宿主 x 量化到对应码本最近元

```
s = Q_{Λ_m}(x) = argmin_{c∈Λ_m}|x-c|
```

提取：看接收点离哪套码本更近

```
m̂ = argmin_{m∈{0, 1}}|y-Q_{Λ_m}(y)|
```

均匀宿主、均匀消息时，量化误差大约在 Δ/4 量级，MSE 随 Δ^2 涨。步长大 → 更鲁棒更吵；步长小 → 更透明更脆。

带补偿的 DC-QIM（减小失真）：

```
s = x + α(Q_{Λ_m}(x)-x), 0<α≤ 1
```

α=1 退回纯 QIM；α< 1 只走一部分路，听感更好、抗噪更差。

#### 5.6.2 格与 Voronoi、陪集

n 维格 Λ={Gz:z∈ℤ^n}，G 是生成矩阵。Voronoi 胞腔：

```
𝒱(Λ) = {x:||x||≤ ||x-λ||, ∀λ∈Λ∖{0}}
```

量化就是把点投到所在胞腔的格点。陪集 Λ+d 是整格平移，QIM 用不同陪集代表不同消息。归一化二次矩（越小越好）：

```
G(Λ) = 1 / (n V^{1+2/n})∫_𝒱||x||^2 dx
```

V=Vol(𝒱)。同样体积下，球堆积更密的格 G(Λ) 更小，量化 MSE 更低。

#### 5.6.3 常见格（你实验用过的）

| 格 | 维数 | 面试一句话 |
|----|------|------------|
| ℤ | 1 | 整数格，基线 |
| A_2 | 2 | 六边形格，平面最密 |
| D_4 | 4 | 棋盘格，中等增益 |
| E_8 | 8 | 8 维极密，量化增益明显 |

MD-QIM：把连续 n 个宿主样本当成一个向量，在 Λ 上量化。维数越高、格越好，同样信息率下平均移动越小。这就是简历里 E8 上 QIM 0.0457、MD-QIM 0.0271 已经先降一截的原因——**还没动消息分布，只是换了几何。**

#### 5.6.4 均匀假设错在哪

设消息 M 的真实分布 P(M=0)=p_0（LDPC 等常有 p_0≈ 0.9），宿主落入陪集 C。经典 QIM 按 P(M=0)=1/2 铺码本，等价于把一半「好位置」（很多宿主已经在、不用动）分给很少出现的 bit 1。需要移动的概率被高估，MSE 里有一项纯属浪费。

#### 5.6.5 CA-QIM：共现 → 重映射 → 边界移动

**(1) 共现统计。** 在训练集上估计

```
P̂(C = c, M = m)
```

**(2) 码本重映射。** 求分配 π：每个宿主陪集 c 优先对应高频消息，使「零移动就能表示目标消息」的概率最大：

```
max_π ∑_cP̂(C = c, M = π(c))
```

（实现上常按共现贪心或匈牙利匹配；口述到「高频消息占更大、更近的区域」即可。）

**(3) 非零移动走 Voronoi 边界。** 若当前点所属陪集与目标消息不一致，不要跳到目标码本中心（那是最远的稳妥点），而是推到两个胞腔的分界面——**刚好能改判、位移最小**：

```
s = x + α(b(x, m)-x)
```

b(x, m) 是指向目标决策域的边界点。这是「最小充分移动」，不是「量化到码字中心」。

#### 5.6.6 非均匀消息下的 MSE 上界（口述推导）

把空间按（宿主陪集、消息）划分。零移动区域贡献 0；移动区域的误差不超过「从胞腔内一点到目标边界/码字」的最大平方距离 D_{max}(c→ m)，或用胞腔二阶矩 𝔼[||X-Q(X)||^2 | c, m]。加权：

```
MSE≤ ∑_{c, m} P̂(c, m) d^2_{π}(c, m)
```

均匀码本相当于 π 无视 P̂(c, m)，界更松。CA-QIM 让 P̂ 大的项对应 d^2≈ 0，所以界和实测一起下降。

**数字（简历，E8，p_0=0.9）：** QIM 0.0457 → MD-QIM 0.0271 → CA-QIM 0.0203，PSNR 64.08 dB。  
PSNR 与 MSE 关系：PSNR=10log_{10}(MAX^2/MSE)，物理层常用归一化幅度，MAX 按你们论文定义说。PRD 是医学信号常用相对失真。

**面试 30 秒版：** 均匀 QIM 假设错了；我用共现改码本，让最常见的比特尽量不用动，必须动就只动到边界。格负责几何增益，重映射负责分布增益，两件事乘在一起。

## 6. 项目四：抗量子密文域信息隐藏系统

2023.04–2023.08｜2023 届全国大学生信息安全作品赛全国三等奖

这个最接近「全栈 + 安全底座」，公司又做区块链和数据，**要主动讲系统，少讲密码论文。**

### 6.1 一分钟 + 架构

图音频隐写容易失真、容易被察觉；RSA/ECC 有量子威胁。我们用后量子密文当载体：密文允许一定扰动仍能解出明文，于是在密文上再藏一层情报。

载体是 FrodoPKE 的 C1/C2。嵌入是 C 域 LSB，物理层比特流用 CA-QIM。误码和提取错误率为 0 时，每元素 2 bit，总容量 10368 bit，大约 1296 个英文字符。系统是双客户端加密/隐写收发，服务端做用户管理和不可篡改日志。我把 CA-QIM 接到 Frodo 载体上，参与客户端嵌入提取、载体池、服务端日志，并写作品说明、参加答辩。

口头架构：

```
客户端 A：明文 → Frodo 加密 → 密文域嵌入
服务端：用户、载体池、审计日志
客户端 B：提取 → 解密 → 明文
```

### 6.2 为什么密文还能再藏

LWE 类加密本身就带噪声。解密能成功，是因为噪声在预算内。LSB 级扰动相当于多加了一点噪声，只要总噪声仍低于阈值，明文不变，附加比特也能抽出来。这是用密码方案的容错当隐写信道，不是把密文当普通图片。

### 6.3 为什么 Frodo 不是 Kyber

Frodo 基于普通 LWE，结构少、分析保守，竞赛里好讲「抗量子、实现清晰」。Kyber 是模格 + NTT，更快，但结构和实现约束更多，密文域乱改更容易踩编码格式。我们优先验证「密文可扰动、容量和零误码」，不是比加密性能。

### 6.4 容量数字怎么解释

每元素 2 bit × 元素个数 = 10368 bit。在我们设定的嵌入强度下，解密和提取都是 0 错误。再加大嵌入会吃噪声预算，出现解密失败，所以容量受密码参数限制，不是隐写码无限加。1296 英文字符是按 8 bit/字符换算，方便非专业评委理解。

### 6.5 「不可篡改日志」别说满

按真实实现说。若是：日志追加写、每条含哈希、上一条哈希指针、管理员不能在界面里改历史，就说「哈希链审计日志，防界面篡改，不是公链共识」。若做了签名或上链，再说签名/上链。没做共识不要说区块链不可篡改。

### 6.6 和全栈岗的关系

这是我最完整的系统经历：账户、载体管理、收发、审计、双端演示。说明我能把算法接到能用的产品，不是停在 notebook。你们要独立交付原型，我用这个证明工程闭环；密码细节不是我来这个岗每天的工作。

### 6.7 原理与公式（LWE / FrodoPKE / 噪声预算 / LSB）

#### 6.7.1 LWE 一句话

密钥 s，随机矩阵 A，小噪声 e：

```
b = As + e (mod q)
```

有噪声时像随机，无噪声 e=0 则是线性方程组可解。量子算法目前没有对一般 LWE 的多项式破解（Shor 打的是 RSA/ECC 的周期问题，不是 LWE）。

#### 6.7.2 FrodoPKE 流程（矩阵版 LWE）

参数模数 q，矩阵尺寸由安全级别定。噪声分布是小整数（离散高斯或 CBD 一类）。

- **KeyGen：** 采样 A、密钥 S 和噪声 E，公钥 B=AS+E。
- **Encrypt(μ)：** 采样 S', E', E''，

```
B' = S'A + E', V = S'B + E'' + Encode(μ)
```

密文就是 (C_1, C_2)=(B', V)。

- **Decrypt：**

```
V-B'S
 = S'E-E'S + E'' + Encode(μ)
approxEncode(μ)
```

因为 S'E, E'S, E'' 都小。再 Decode 还原 μ。

**人话：** 解密靠「交叉项噪声加起来还不够翻过量化格子」。Encode 一般是把比特放到系数的高位，中间留间隙当容错。

#### 6.7.3 为什么密文还能 LSB 嵌入

把 C_1 或 C_2 的系数最低 1–2 bit 改掉，等价于再加一个有界扰动 e_{steg}：

```
Ṽ = V + e_{steg}
```

解密变成 Encode(μ)+e_{nat}+e_{steg}。只要

```
||e_{nat} + e_{steg}||_∞ < Decode 容限
```

明文不变，同时这些 LSB 就是隐写信道。容量：每系数 2 bit × 系数个数 = 10368 bit（约 1296 字节/英文字符，按 8 bit 计）。再加码率会顶满预算 → 解密失败，所以零误码是「嵌在容限内」，不是密码被攻破。

物理层比特流再套 CA-QIM：先把情报编成偏 0 的比特，再按 5.6 节量化到更适合的陪集，进一步压扰动幅度，给噪声预算留余量。

#### 6.7.4 和 Kyber 的差别（别讲错）

Kyber 用模格 R_q=ℤ_q[x]/(x^n+1) 和 NTT 乘多项式，密文有固定编码、压缩。乱改 bit 更容易碰到压缩/NTT 约束。Frodo 是普通矩阵 LWE，系数更「平」，竞赛里当载体更直观。Kyber 更快、NIST 主推 KEM；我们优化目标是验证信道，不是 TLS 握手性能。

#### 6.7.5 哈希链日志（系统侧公式）

```
h_i = H(payload_i||h_{i-1}||t_i)
```

改历史任意一条，后面哈希全对不上。这是审计完整性，**不是**共识，不要说区块链。

## 8. Agent（JD 50%，必考）

### 8.1 Agent 和普通 chatbot 差在哪

Chatbot 主要是下一句回复。Agent 是：理解目标 → 选工具 → 执行 → 看结果 → 再决策，直到任务结束或交给人。差在工具、状态、终止条件和失败恢复。内部知识问答如果只是单次 RAG，不必硬上 Agent；要查多源、写回工单、触发生成、等人确认，才值得上。

### 8.2 现场画的架构

```
用户目标
  → Planner（拆步骤、选工具）
  → Tool Agents（检索 / 业务API / 代码 / 水印检测 等）
  → 观察与短期记忆
  → Critic（检查是否完成、是否幻觉）
  → 回复或追问
长期记忆：向量库 + 业务库
人机：高风险步骤确认、超时重试、人工接管
```

复杂场景才拆多 Agent：角色不同、工具权限不同、或需要互审。简单问答拆多 Agent 只会加延迟、成本和级联错误。

### 8.3 ReAct 是什么

- Thought：下一步为什么这么做。
- Action：调用哪个工具、参数是什么。
- Observation：工具返回。
- 再 Thought。直到可以 Final Answer。

好处是可追踪。坏处是模型可能死循环、编造工具结果。所以要：最大步数、工具白名单、超时、对观察做校验、禁止模型伪造 Observation。

### 8.4 多轮对话怎么设计

- 状态：当前任务、已填槽、已引用文档 ID、未完成工具。
- 指代：「把刚才那个再查一遍」要绑上一步的实体。
- 上下文：超长就摘要 + 关键槽位结构化，不只靠把聊天记录全塞进去。
- 澄清：缺必填槽就问人，不要猜着调删除、转账、覆盖写类工具。

### 8.5 LangChain / LlamaIndex

LangChain：链、工具、Agent 编排生态大，生产里常嫌抽象重，但原型快。  
LlamaIndex：索引、检索、文档连接更强，适合 RAG 中台。  
落地偏好：原型可以用框架；核心路径倾向官方 SDK + 自己的状态机，方便控日志、重试和权限。理解概念比绑死某个库重要。

### 8.6 一周做一个内部知识库问答 MVP

- Day 1：问清楚用户是谁、10 个真实问题、成功标准（答对、要引用、不能编）。
- Day 2：文档接入、切分、向量库、最小检索 + 生成。
- Day 3：引用、拒绝回答、简单多轮。
- Day 4：评测集 30–50 题，看召回和幻觉。
- Day 5：一个工具（工单查询或水印检测）做成 Agent 路径。
- Day 6：异常、超时、日志、简单页面。
- Day 7：和业务一起看失败 case，定下一周：重排、权限、缓存。

这就是 JD 说的独立端到端原型，不是先搭完美中台。

### 8.7 结合背景的 Agent 例子

内容确权助手：上传图或音频 → 调提取/检测工具 → 查库或对哈希 → 生成报告（是否有水印、置信度、建议）。人只在低置信度时介入。这能证明我懂工具编排，也接得上研究院的数据与版权场景。

### 8.8 Agent 必须能说的点

- Function Calling / Tool Schema
- 多 Agent：什么时候拆、什么时候不要拆
- 失败处理：工具超时、幻觉调用、循环、权限

### 8.9 原理：LLM 目标、解码、ReAct、工具调用

#### 语言模型目标

给定上文 w_{<k}，预测下一个 token：

```
ℒ_{LM} = -∑_{k} log p_θ(w_k | w_{<k})
```

Chat/SFT 只在 assistant 片段上算损失，系统提示和用户话不回传梯度（mask）。这是「教它按格式说话」，不是再做一遍预训练。

#### 解码（会被问）

softmax 温度：

```
p_i = exp(ℓ_i/T) / ∑_jexp(ℓ_j/T)
```

- T→ 0：近似 greedy，稳但死板。
- T 大：更随机。
- top-k：只保留 logit 最大的 k 个再归一化。
- top-p（nucleus）：按概率从大到小累加到 p 再截断。

Agent 调工具时常用低 T / greedy，减少胡编函数名。

#### Function Calling

模型不是真的「执行」，只是生成一段结构化参数，例如

```json
{"name": "search", "arguments": {"q": "..."}}
```

运行时校验：名字在白名单、JSON schema 能 parse、权限足够，才真正调。Observation 写回上下文再生成下一步。伪造 Observation 必须禁止（只允许后端写入）。

#### ReAct 作为策略

每步采样

```
a_t∼ π_θ(·| s_t), s_{t+1} = Env(s_t, a_t)
```

s_t 是对话 + 工具史。终止：Final Answer、步数上限、或人工接管。循环检测：同一工具同一参数连续命中则打断。

## 9. RAG（JD 30%，必考）

### 9.1 标准流水线

1. 解析：PDF/HTML/表格，尽量保标题和表结构。
2. 切分：chunk 过大噪声多、过小没上下文；按标题或语义切，留重叠。
3. 嵌入 + 向量库。
4. 检索：向量 + BM25 混合，专名和编号更稳。
5. 重排：bge-reranker 一类，只把 top-k 给模型。
6. 组装 prompt：问题 + 片段 +「必须引用、没有就说不知道」。
7. 评测：召回、答案正确、是否忠实于片段、拒答是否合理。

### 9.2 检索不准怎么查

按层排：

- 文档是否切对、表格是否碎掉
- embedding 是否适合中文/领域
- 召回 top-k 里有没有金答案（没有就是检索问题，别先怪 LLM）
- 有金答案但没用来答，是重排或 prompt
- 用来答了但编了片段外信息，是生成约束不够

### 9.3 RAG vs 微调 vs 蒸馏

- 知识常变、要引用、要可追责：RAG。
- 固定格式、语气、工具使用习惯、领域推理：微调。
- 要小模型、降成本、边侧署：蒸馏，教师可以是大模型或已微调模型。

业务常是 RAG 为主，少量 SFT 教「怎么引用、怎么拒答」，不要一上来全参训 7B。

### 9.4 幻觉怎么压

检索阈值、强制引用、无命中则拒答、答案和片段做一致性检查、关键数字用工具而不是让模型抄。评测要单列「编造率」，不要只看流畅度。

### 9.5 还会被问

- chunk 太大/太小会怎样
- 为什么 hybrid（BM25 + 向量）
- 知识更新：增量索引、过期文档

### 9.6 原理与公式（嵌入、检索、BM25、重排）

#### 嵌入相似度

文档块 d、查询 q 经同一（或双塔）编码器得到 ℓ_2 归一化向量，余弦 = 点积：

```
sim(q, d) = e(q)^T e(d)
```

向量库做近似最近邻（HNSW / IVF），取 top-k。阈值 τ：max_dsim<τ 则拒答。

#### 切分

块长 L、重叠 o。L 太大：噪声多、嵌入被冲淡；L 太小：没有完整事实。重叠是为了避免句子在边界被切断。经验：中文 300–800 字、按标题切，表格尽量整表或整行。

#### BM25（稀疏，专名友好）

对词 t：

```
IDF(t) = ln((N-n_t + 0.5) / (n_t + 0.5))
```

```
BM25(q, d) = ∑_{t∈ q} IDF(t)·(f(t, d)(k_1 + 1)) / (f(t, d) + k_1(1-b + b·|d|/avgdl))
```

f 是词频，k_1, b 是超参。编号、人名、条款号向量模型容易糊，BM25 能抓住字面。

#### 混合检索

```
score = λ norm(sim) + (1-λ) norm(BM25)
```

或 Reciprocal Rank Fusion：∑_i 1/(k+r_i)。然后再用交叉编码器 rerank（query 和 doc 拼在一起过 Transformer 打分），只把前 n 条（如 3–8）给 LLM。

#### 生成时的忠实度

把检索片段当条件：p(a | q, d_1, …, d_n)。评测不要只看流畅：

- Recall@k：金文档有没有进检索。
- 答案正确 vs 片段忠实（有金句却编了数字，算幻觉）。

## 10. 模型工程（硬性要求）

### 10.1 微调我做过什么

VLM 项目就是在 CLIP / BLIP / SigLIP 上微调。区分：

- **全参：** 改动大，水印或领域适应强，贵，容易伤通用能力。
- **LoRA：** 低秩补丁，适合注入风格、协议、轻量任务，回滚容易。
- **QLoRA：** 量化后再 LoRA，显存不够时用。

业务「最后一公里」优先 LoRA + 小而干净的数据；水印那种要和主表示绑紧的信号，才考虑更大更新，并用主任务指标守门。

### 10.2 蒸馏

大模型出数据或出 logit，小模型学。目的是部署成本和延迟，不是追求比教师更强。要有学生自己的评测集，防止只学会教师的废话。我有「加约束后主任务掉点」的评测习惯，可以迁过来。

**公式：** 教师 p_T、学生 p_S，温度 T 软化：

```
ℒ_{KD} = T^2 KL(softmax(ℓ_T/T) || softmax(ℓ_S/T))
 + λ CE(y, p_S)
```

也可以只对学生生成教师的回答（数据蒸馏），不必对齐全部 logit。特征蒸馏则对齐中间层。T 大：教师分布更软，学生学类别之间的相似关系。

### 10.3 vLLM

服务化推理框架。两个点：

- **PagedAttention：** KV cache 按页管，减少碎片，提高并发。
- **连续批处理：** 请求随时进，按 token 造批，提高吞吐。

关注：并发下的 TTFT、TPOT、吞吐、显存。适合多用户 API。不是训练框架。

**原理（能画就加分）：** Transformer 每层每个 token 要缓存 K, V。序列长度 L、层数 n、头数 h、头维 d，粗估

```
KV bytes≈ 2·n_{layers}·L·n_{kv heads}·d·b
```

b=2 为 FP16。传统实现按「最大长度」整块预分配，短请求浪费、变长请求碎片多，并发上不去。PagedAttention 把 KV 切成固定页（类似 OS 虚拟内存），逻辑连续、物理散页，块表映射。请求结束立刻还页。

连续批处理：decode 阶段每步各请求只出一个 token，把这些 token 打成一批；新请求的 prefill 可以插进来。于是显存按真实占用走，吞吐随并发升。

指标：

- TTFT：首 token 时间（prefill，和提示长度有关）
- TPOT：每输出 token 时间（decode，和 batch、KV 有关）
- 吞吐：tokens/s

### 10.4 TensorRT-LLM

把模型编成 TensorRT 引擎，kernel 融合、量化、固定形状优化。适合模型相对固定、要极致延迟/吞吐的私有化。换模型、改结构的成本高于 vLLM。内部工具先 vLLM 迭代；模型定了、要压机器，再上 TRT-LLM。

图优化把 LayerNorm、GEMM、激活融成更少 kernel，减少显存往返。动态 shape 支持比 vLLM 麻烦。量化常和 TRT 一起做。

### 10.5 量化

INT8 / INT4 降显存和带宽。AWQ / GPTQ 是权重量化常见做法。风险是小模型量化后指令遵循变差。上线前用同一套业务题回归，不只看 perplexity。

均匀量化示意：

```
ŵ = clip(roundw/s, q_{min}, q_{max})·s
```

GPTQ：用二阶信息逐层减小量化误差。AWQ：保护激活幅度大的通道（scale 再量化）。KV cache 量化还能再挤并发。口述抓住：**权重量化换显存和带宽，激活/KV 另算；必须业务回归，PPL 只是参考。**

### 10.6 私有化 7B/14B 怎么选

先定并发和延迟。单卡 7B 常用 vLLM + AWQ/GPTQ；14B 看显存决定是否量化或两卡。先保正确率，再压速度。没有流量数据时，用 vLLM 打一条基线，再决定要不要 TensorRT。

### 10.7 效果评测（把强项说满）

AI 好不好不能靠体感。我做过：主任务精度、水印成功率、PSNR/SSIM、PESQ/MOS、攻击后还剩多少。迁到 Agent：

- 任务成功率
- 平均工具步数、延迟、成本
- 幻觉率、拒答是否该拒
- 人工介入率

先定 30 条真实任务当回归，再谈上线。这是和「只会调 prompt 的人」的差别。

| 评测 | 自动指标 + 人工；现成故事：水印检测率、主任务掉点、PESQ |

结合经验：

> 我评过「加水印后主任务掉多少、攻击后还能不能检出」。做业务模型也一样：先定回归集，再谈上线。

## 11. 图视频生成 / ComfyUI

我没把 ComfyUI 当生产主业，但生成流水线做过：音频是扩散 + vocoder；图像侧有 DWT 和 VLM。ComfyUI 是节点图：读模型 → prompt → 采样器 → VAE 解码 → 超分/插帧/保存。工程问题是显存、种子复现、LoRA 热插拔、批量和质量回归。

若要我做图视频方向：先把能复现的工作流固化成 API（模型和种子可记录），用 FID/CLIP-score 或业务人工分做回归；需要确权就在 VAE 后或潜空间加嵌入节点。没跑过的节点不装熟，但流水线、指标、插入点我有迁移经验。

文生图口头知识：DiT/UNet、CFG 越高越贴 prompt 但可能过饱和、步数换质量、采样器影响风格。视频再加时序一致性和插帧。

即使没做过 ComfyUI，也要能说：

- 文生图：UNet/DiT、CFG、sampler、步数 vs 质量
- 工作流：加载模型 → prompt → 采样 → VAE 解码 → 超分/视频插帧
- 工程问题：显存、batch、LoRA 热插拔、种子复现
- 连接点：生成流水线里插入水印节点；或用质量指标（PSNR/SSIM/PESQ）做回归

### 11.1 原理与公式（LDM / VAE / UNet·DiT / CFG / FID）

和音频扩散是同一套 x_t=√(α̅_t)x_0+√(1-α̅_t)ε，只是 x_0 换成图像 latent。

**VAE：** 图像 x → 编码器给 μ, log σ^2，z=μ+σ⊙ε，解码 x̂。损失重构 + KL 拉向标准正态。Stable Diffusion 在这个 z 上扩散，空间大约是像素的 1/8，算力从 H×W 降到 h×w。

**UNet：** 下采样–中间–上采样，skip 连接保留空间细节；文本用 cross-attn：Q 来自图像特征，K, V 来自文本 token。

**DiT：** 把 latent 切 patch，用 Transformer + AdaLN 注入时间步和条件，是 SD3/Sora 系的骨干。口述：「同一套注意力，条件通过自适应归一化进去。」

**CFG：** 与 4.10.4 相同，ε̃=ε_∅+s(ε_c-ε_∅)。s 常取 7–12（图）或更低（有的模型 3–5）。高 s 更贴词、更假、更过饱和。

**采样器：** Euler/DPM++/DDIM 都是解同一概率流 ODE 的不同离散；步数 20–30 常够，再加边际小。种子固定 + 确定采样才能复现。

**FID：** 用 Inception 特征的高斯拟合，

```
FID = ||μ_r-μ_g||_2^2 + Tr(Σ_r + Σ_g-2(Σ_rΣ_g)^{1/2})
```

测分布距离，不保证单张图语义对。CLIP-score 补「图和 prompt 是否对齐」。视频还要时序一致性（相邻帧差、光流）。水印节点：VAE decode 之后或 latent 里，和音频「vocoder 前/后」是同一问题。

## 附录 A. 公共底座公式（交叉熵、KL、归一化、编码、相关工作）

项目里反复用到、面试也可能单独抽问。和前面章节重复的，这里给更完整的「手推公式」。

### A.1 交叉熵、KL、softmax

多分类真实分布 p（one-hot）、模型 q=softmax(ℓ)：

```
CE(p, q) = -∑_i p_ilog q_i
```

对 one-hot 标签 y：CE=-log q_y。KL：

```
KL(p||q) = ∑_i p_ilog(p_i / q_i) = CE(p, q)-H(p)
```

H(p) 与模型无关，所以 **最小化 CE 和最小化 KL 在监督学习里等价**。蒸馏时 p 是教师软标签，H(p) 不是常数意义上的「可忽略」，但仍常直接优化 KL(p_T||p_S)。

**约束干净输出为什么常用 KL 而不是 CE：** CE 对着硬标签会把概率推到 1；KL 对着原模型分布，是「保持原来的软行为」，更适合「不要忘事、不要乱触发」。

softmax 对 logit 的梯度：∂ q_i/∂ℓ_j=q_i(δ_{ij}-q_j)。温度 T 相当于把 ℓ 除以 T，分布变平。

### A.2 残差、LayerNorm、位置编码

残差：out=x+F(x)，梯度可走捷径，深层才训得动。

LayerNorm（对最后一维，每个 token 独立）：

```
x̂ = (x-μ) / (√(σ^2 + ε)), y = γodotx̂ + β
```

和 BatchNorm 的差别：BN 沿 batch 统计，推理要跑均值；LN 无此问题，NLP/ViT 更常用。

位置：绝对可学习表；正弦；RoPE 把旋转作用在 Q/K 上，相对位置写进点积。知道「没位置编码注意力置换不变」即可。

### A.3 显存账（微调时能算）

参数 FP16：2|θ| 字节。Adam 还要 m、v（常 FP32），大约再 8|θ|。激活与 batch、序列长度、层数成正比。所以：

- 全参 7B 训不动就 LoRA：只存小矩阵梯度。
- 梯度检查点用时间换激活。
- 梯度累积：物理 batch=1，逻辑 batch=累加步数，对比学习的负样本数仍受物理 batch 限制（这点 CLIP 微调要诚实说）。

### A.4 重复码 / 汉明 / BCH（音频多比特）

重复 n 次、多数表决：能抗大约 ⌊ n/2⌋ 个比特翻转，码率 1/n。  
汉明 (7, 4)：4 信息位 3 校验，纠正 1 位错。  
BCH/RS：纠更多突发错误，适合压缩造成的成片误码。  
口述：**容量让给纠错**，确权 ID 只要几十 bit，不要追求藏一篇文章。

### A.5 SSIM（比 PSNR 多说一句）

对窗口内亮度 μ、方差 σ：

```
SSIM(x, y) = ((2μ_xμ_y + C_1)(2σ_{xy} + C_2)) / ((μ_x^2 + μ_y^2 + C_1)(σ_x^2 + σ_y^2 + C_2))
```

接近 1 更好。DWT 水印要同时报 PSNR 和 SSIM：PSNR 对均匀噪声敏感，SSIM 对结构更敏感。

### A.6 E_8 格（加分，不会就停在「8 维密堆积」）

E_8 可看成 ℝ^8 中所有坐标为整数或半整数、且坐标和为偶数的点。它是 8 维最密格之一，kissing number 240，G(E_8) 明显小于 ℤ^8。面试不要求背生成矩阵；要求：为什么同样 Δ 下 E8 的 MSE 比 Z 小——**Voronoi 更圆，平均量化误差更低**。

### A.7 相关工作（避免「只知道自己」）

- **HiDDeN：** 端到端编码器–噪声层–解码器，损失 = 图像失真 + 消息 BCE，噪声层模拟 JPEG/裁剪。
- **StegaStamp：** 强鲁棒的深度学习图像水印，针对拍照再摄。
- **BadEncoder / 后门水印：** 在自监督编码器里注入触发，验证用触发集准确率。
- **Kirchenbauer：** 见 3.16.8。
- **AudioSeal / WavMark：** 神经网络音频水印，多在波形或 STFT 上；你的差别是**进扩散生成过程**。

公开方法用这些名字；自己论文的独特损失不要对外默写未刊公式。

### A.8 手推清单（明天白纸能写就过关）

1. Attention：Q=XW_Q, K=XW_K, V=XW_V，softmax(QK^T/√(d_k))V；一层 = 注意力 + FFN + 两处残差
2. CLIP：对称 InfoNCE，s_{ij}=f^T g/τ
3. SigLIP：log σ(±(t x^T y+b))
4. LoRA：W_0+BA
5. DDPM：x_t=√(α̅_t)x_0+√(1-α̅_t)ε，损失 ||ε-ε_θ||^2
6. CFG：ε_∅+s(ε_c-ε_∅)
7. QIM：两套码本量化；CA-QIM 再加非均匀重映射
8. LWE：b=As+e，Frodo 解密噪声预算
9. PSNR：10log_{10}(MAX^2/MSE)
10. BM25 + 余弦混合检索

每条配一句人话，见各章「人话」段。公式写对但说不出来，仍会减分。

## 附录 B. 口述时公式怎么讲（避免现场沉默）

推荐句式：**「形式化是……，直观上就是……，我们实验里对应……。」**

例（CLIP）：「形式化是 batch 内图文相似度做对称交叉熵；直观上就是配对要近、不配对要远，温度控制有多狠；我们加水印等于多了一批特殊正对，同时还要用干净样本 KL 把主任务钉住。」

例（扩散水印）：「形式化是在 ε_θ 或 x_T 上加密钥决定的偏移；直观上就是生成轨迹自带身份；实验用 SNR/PESQ 看偏移有没有吵到人，用压缩裁剪看还能不能抽出来。」

例（CA-QIM）：「形式化是陪集–消息共现上的码本分配，加边界最小移动；直观上 90% 都是 0，就别强迫一半格点给 1 预留；E8 上 MSE 从 0.0457 降到 0.0203。」

现场推不出来完整积分时，停在这三句，不要硬编上界的每一步。
