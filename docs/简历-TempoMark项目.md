**面向生成音频的时序对齐水印（TempoMark）**  
2024.08 – 2025.08｜2026 届全国大学生信息安全竞赛作品赛；相关方法已整理为学术论文（审稿中）

- **项目需求：** 生成音频易再分发，需要可恢复的多比特载荷做来源/授权验证。事后嵌入和声学载体不在生成轨迹内，去噪、再生成或声码器重建后比特易丢失或混叠；部分生成式方法把载荷写成无结构潜空间扰动，多比特纠缠、提取时还要搜时延。需要编解码共用同一套时间网格、能在冻结扩散声码器轨迹上稳定恢复的方案。
- **方法设计与模型开发：** 提出 TempoMark：在**冻结的扩散声码器**去噪轨迹上嵌入多比特载荷。编码端将每个 bit 分到固定时长的时间槽，用带通载波做 BPSK，再按 chip 扩频，得到与槽边界对齐的水印波形；注入时以该波形的等长带通拷贝作为主残差，adapter 只做小修正，在去噪中间步加到从共享起点出发的一段连续区间上。解码端不搜索时延，按同一套槽长、chip 长和时间网格做匹配滤波，并以很小权重混入 Mel-CNN 残差、由 matched 主导恢复。训练只更新 adapter 与解码侧参数，用攻击后 BCE、干净音频对比项和波形一致性平衡可提取性与音质。核心是编解码共用时间网格，而不是依赖某一固定时延。评测覆盖有效性、PESQ/SNR/MOS 等听感，以及重采样、MP3、低通、加噪、裁剪等失真。
- **工作内容：**
  - **问题分析：** 归纳事后/声学载体/无结构潜空间扰动在再处理后的失效原因，将目标定为轨迹内、按时间槽可分的多比特嵌入。
  - **方法实现：** 负责时间槽–BPSK–扩频编码、冻结扩散轨迹上的残差注入、匹配滤波解码与轻量 Mel-CNN 残差融合；训练 adapter/解码器及攻击后 BCE 等损失。
  - **实验：** 完成听感与失真/去水印评测。
  - **论文：** 撰写方法与实验，整理为投稿论文（审稿中）。

**技术栈：** Python / PyTorch，扩散声码器（冻结生成轨迹），Mel / 带通时频，BPSK 与扩频，匹配滤波，轻量 Mel-CNN，PESQ / SNR / MOS。

**精简版（一页纸用）**

> 针对生成音频溯源，在冻结扩散声码器的去噪轨迹上做多比特水印 TempoMark：按固定时间槽做 BPSK+扩频，槽对齐注入；解码按同一时间网格匹配滤波（不搜时延），辅以轻量 Mel-CNN。只训 adapter 与解码器，用攻击后 BCE、对比项和波形一致性保提取与音质。评测 PESQ/SNR/MOS 及压缩、滤波、加噪、裁剪。PyTorch。论文审稿中。
