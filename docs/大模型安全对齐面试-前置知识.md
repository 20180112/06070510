## 1. 今晚必过：安全对齐这条线（按这个顺序）

### 1.1 三个目标（HHH）

- [ ] **Helpful** 有用；**Harmless** 无害；**Honest** 不瞎编。三者常冲突（拒太多 → 没帮助；太顺从 → 不安全）。
- [ ] 岗位里的「安全性与帮助性」就是在调这个折中。

### 1.2 训练阶段（必须能画）

```
预训练（网页/书） 
  → SFT（指令数据，含安全拒答示范）
  → 偏好对齐（RLHF / DPO 等）
  → 可选：持续在线对齐、护栏（分类器/规则）
```

- [ ] **SFT：** 交叉熵学「怎么答」；安全 SFT = 数据里大量「拒绝有害请求 + 仍帮助良性请求」。
- [ ] **RLHF 三件套：** ① 偏好数据（回答 A 优于 B）② **奖励模型 RM** 拟合人类偏好 ③ **PPO** 用 RM 打分更新策略，并用 **KL** 把模型拉住、别离 SFT 太远。
- [ ] **DPO：** 不用单独 RM + PPO，直接用偏好对更新策略，实现更简单，工业界很常见。
- [ ] **KL 惩罚：** 防 reward hacking（刷高分但胡言、重复、讨好）。

被问「你做过吗」：对齐流程是了解，实验主线是水印多目标训练，不是 RLHF。

### 1.3 岗位三个方向分别是什么

**方向 1 全流程安全对齐**

- [ ] 预训练：过滤有害语料、文档级标注（了解即可）。
- [ ] 后训练：安全 SFT + 偏好对齐；有时在损失里加安全分类器或约束解码。
- [ ] 「写入架构」：如拒绝头、路由、混合专家里的安全专家——知道有这种思路即可。

**方向 2 内生防御 vs 外挂护栏**

- [ ] **外挂：** 输入/输出分类器、关键词、正则，好部署、易被绕过。
- [ ] **内生：** 模型自己会拒、会解释、少幻觉；难、要训。
- [ ] 岗位要轻量 + 能推理 + 防有害 / Agent / 幻觉，还要体验和性能。

**方向 3 在线持续对齐**

- [ ] 上线后用日志、人工/模型标注、新攻击样本再 SFT/DPO。
- [ ] 「自愈」= 对新越狱尽快补数据再对齐，不是模型自己长出免疫。
- [ ] 监控：拒答率、越狱成功率、有用性、延迟。

### 1.4 威胁词表（会定义、各举一例）

- [ ] **越狱 jailbreak：** 伪装、角色扮演、多轮把模型绕出拒答。
- [ ] **有害内容：** 暴力、违法、自伤、色情等（按公司政策）。
- [ ] **过度拒绝 over-refusal：** 正常问题也拒，伤害帮助性。
- [ ] **幻觉：** 无依据的事实；安全场景下「一本正经给错医疗建议」也是风险。
- [ ] **提示注入：** 网页/工具返回里藏「忽略系统提示」。
- [ ] **Agent 安全：** 乱调工具（发邮件、付款、读隐私）；权限、确认、沙箱。
- [ ] **模型窃取/蒸馏：** 你水印更熟——所有权，不是内容安全，可作补充。

### 1.5 可控生成（和你最近）

- [ ] 解码约束：bad word、安全分类器引导 logits。
- [ ] 条件生成：系统提示、安全模式。
- [ ] 你的工作：特定图文条件才激活水印响应；生成侧改采样/logits。可说「条件化输出」，再声明目标是溯源不是拒答。

- [ ] **PyTorch：** 你有。
- [ ] **Megatron：** 大模型张量/流水并行，预训练用。

## 2. 水印项目怎么答才不像跑题

**一句话定位：** 我做的是生成模型的 **版权与溯源**（训练侧所有权、生成内容可提取标识），不是 RLHF 拒答；共同处是在大模型训练目标里加约束、并评后训练攻击。

**可迁移（主动讲）：**

1. 多损失联合：主任务 + 水印 + 规避项 ≈ 「有用」和「安全约束」一起优化。  
2. 后训练鲁棒性：微调/剪枝/量化后行为是否还在。  
3. VLM 全链路：编码器–对齐–语言模型推理，对应岗位 VLLM。  
4. 生成可控：条件触发、采样侧修改。  
5. 评测设计：成功率 vs 主任务 vs 隐蔽性，对应安全 vs 帮助性 vs 体验。

**被问 RLHF 经验：** 没有完整 RM+PPO；能讲清流程和 DPO 在优化什么；愿意用安全数据做 SFT/LoRA。
