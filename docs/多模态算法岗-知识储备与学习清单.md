## 1. 第一优先：面试几乎必问

### 1.1 Transformer 与视觉编码器

- [ ] Self-Attention 公式、Q/K/V、缩放点积为什么要除 \(\sqrt{d}\)
- [ ] 多头注意力、残差连接、LayerNorm、FFN 的位置和形状
- [ ] 位置编码：绝对 / 可学习 / RoPE（知道差别即可）
- [ ] 能画：token 序列 → Transformer block → 输出
- [ ] 计算复杂度 \(O(n^2)\)，长序列为什么贵
- [ ] ViT：patch embedding、class token、和 CNN 的差别
- [ ] 能画：图像 → patch → ViT → 特征

**学到什么程度：** 白纸能画出 ViT + 一层 Transformer，能手写注意力伪代码。

### 1.2 多模态对齐（项目底座，必须能讲课）

- [ ] CLIP 双塔结构：图像塔、文本塔、共享温度 \(\tau\)
- [ ] InfoNCE / 对比学习在 CLIP 里怎么做，正负样本是什么
- [ ] CLIP 怎么做图文检索、zero-shot 分类
- [ ] 对齐（alignment）、融合（fusion）、指令微调（instruction tuning）三者区别
- [ ] BLIP / BLIP-2：Q-Former 解决什么问题（相对「视觉 token 全塞进 LLM」）
- [ ] LLaVA：投影层（linear / MLP）把视觉特征映到 LLM 词空间
- [ ] LLaVA 两阶段：特征对齐 → 指令微调，各自冻什么、训什么
- [ ] 能画：图像 → ViT → 投影 → LLM → 文本

**学到什么程度：** 能对着纸讲完 CLIP 一次前向 + LLaVA 数据流，能回答「为什么不把 ViT 所有 patch 直接拼进 LLM」。

### 1.3 训练与微调

- [ ] 交叉熵：分类、语言模型 next-token 各怎么用
- [ ] 对比损失 InfoNCE，温度系数过大/过小会怎样
- [ ] KL 散度：蒸馏、约束输出分布（与交叉熵的差别）
- [ ] LoRA / QLoRA：低秩更新加在哪、为什么省显存
- [ ] 冻结视觉编码器、只训投影层 / LoRA 的原因
- [ ] 过拟合、灾难性遗忘、学习率、warmup
- [ ] 对比学习为什么常要大 batch（能讲到 CLIP 即可）
- [ ] 混合精度 AMP、梯度累积
- [ ] 多卡：DataParallel vs DistributedDataParallel 概念差别

**学到什么程度：** 给定「只想在一张 24G 卡上微调 LLaVA」，能说出冻哪些层、用 LoRA、梯度累积、混合精度。

### 1.4 生成模型（对上音频项目）

- [ ] 扩散：前向加噪、反向去噪、网络预测的是噪声还是 \(x_0\)
- [ ] 条件生成：文本条件如何进入 U-Net / DiT（AdaLN、cross-attn 知道一种即可）
- [ ] 扩散 vs 自回归（GPT、codec + LM）差在哪
- [ ] DDPM vs DDIM 采样（项目里用过，可当开口）
- [ ] 潜空间：VAE、Mel 频谱、latent diffusion 各自压缩什么
- [ ] classifier-free guidance 在做什么（知道即可）

**学到什么程度：** 能讲「一条 Mel / latent 如何从噪声变成音频」，以及水印若写在生成过程中，大致作用在轨迹的哪一段（不必讲未发表细节）。

### 1.5 评测（你会做实验，要能解释指标）

- [ ] 分类 / 检索：Accuracy、Recall@K
- [ ] 图像 / 音频生成：FID、FAD 衡量什么、坑在哪
- [ ] 听感与语义：PESQ、SNR、CLAP、MOS
- [ ] 文本生成：困惑度 PPL 高/低意味着什么
- [ ] 水印场景：主任务掉点 vs 可检测率如何折中（用自己项目答）

**学到什么程度：** 面试官报一个指标，你能说它测的是失真、语义还是可提取性。

## 2. 第二优先：多模态算法日常会用到

### 2.1 数据与任务

- [ ] 图文任务：caption、VQA、检索、grounding / 定位
- [ ] 常见数据叫得出：COCO、VQA v2、LAION（知道用途即可）
- [ ] 预处理：分辨率、patch 数、tokenizer、截断与 padding
- [ ] 多轮对话数据里 image token 一般插在哪

- [ ] 解码：greedy、top-k、top-p、temperature
- [ ] BPE / SentencePiece、special token
- [ ] SFT 数据格式（instruction、多轮、image 占位）

### 2.3 工程

- [ ] `Dataset` / `DataLoader`、collate、DistributedSampler
- [ ] HuggingFace：`transformers`、`peft`，如何 load、freeze、保存

- [ ] 看懂一份官方 LLaVA / CLIP 微调脚本的数据流

### 2.4 经典面试题型（单独抽时间刷）

## 5. 对照简历的 20 道自测题

先闭卷答，再查缺。不会的回到第 1、2 节对应条目。

1. CLIP 的 InfoNCE 对一个 batch 里的一张图，正样本和负样本分别是什么？
2. 温度 \(\tau\) 变小，CLIP 训练会更「尖锐」还是更平滑？对检索有什么影响？
3. 为什么 LLaVA 通常先冻 LLM 和 ViT、只训投影层？
4. Q-Former 和「所有视觉 token 进 LLM」各有什么代价？
5. LoRA 的 \(A,B\) 矩阵形状和秩 \(r\) 怎么影响参数量？
6. 交叉熵和 KL 散度，约束「单侧触发仍像干净输出」时为什么有人用 KL？
7. ViT 的 patch size 变小，序列长度和算力如何变？
8. Attention 为什么要除 \(\sqrt{d_k}\)？
9. DDPM 和 DDIM 的主要差别是什么？加速采样牺牲什么？
10. latent diffusion 相对像素空间扩散省在哪里？
11. FID / FAD 对不齐语义时会发生什么？CLAP 补的是哪一块？
12. PESQ 高是否等于「水印一定不可感知」？为什么还要 MOS？
13. 冻结 ViT、只在嵌入空间动触发器 / 条件，和全量微调水印，鲁棒性可能差在哪？
14. 结构化剪枝为什么可能同时伤主任务和水印？说明了什么耦合关系？
15. DataParallel 和 DDP 的梯度同步差在哪？对比学习大 batch 更倾向哪个？
16. top-p 和 temperature 同时调大，生成文本会怎样？
17. 图文检索 Recall@1 和分类 Accuracy 能否互相替代？
18. 灾难性遗忘在「二次微调去水印」设定里指什么？
19. 把视觉特征线性投到 LLM 词空间，和训练一个跨模态融合 Transformer，各适合什么？
20. 用自己的话讲：多模态算法岗关心的「对齐」，和你项目里的「跨模态条件」，交集是什么、差别是什么？
